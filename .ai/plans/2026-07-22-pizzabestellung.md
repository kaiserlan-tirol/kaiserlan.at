# Pizzabestellungs Modul

Admin Eingabefelder:

- Pizzen Zeile für Zeile
  `name;description;price`
- Bestellung offen ab <datetime>
- Bestellung möglich bis <datetime>

Benutzer können eine oder mehrere Pizzen bestellen, jede Pizza wird im Catering per "Guthaben reduzieren" erfasst mit Notiz: "Pizza: name der pizza"

Benutzer haben in ihrem Catering Dashboard zusätzlich einen Button "Pizzabestellung für Samstag, bis HH:00", dieser führt zur pizza bestellseite.
Selbes look and feel wie die normale catering Bestellung, nur statt der anderen Produkte eben die Pizzen.
